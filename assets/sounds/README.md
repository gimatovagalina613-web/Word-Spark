# WordSpark sound effects

The sound manager looks for these optional replacement files:

- `click.mp3`
- `flip.mp3`
- `correct.mp3`
- `wrong.mp3`
- `next.mp3`
- `reward.mp3`
- `complete.mp3`
- `sparky.mp3`

Until a file is added, WordSpark automatically uses a short synthesized Web Audio
fallback. Files can therefore be replaced individually without changing JavaScript.
